點樣將呢個檔案變成真實嘅 http:// 網站？

零成本、免買伺服器，將網頁擺上網隨時隨地用！

優點

擁有專屬嘅 HTTP/HTTPS 網址（例如 https://yourname.github.io/daytrade），全免費、永久有效，手提電話或平板都睇得到！

  1. 註冊免費 GitHub 帳號：去 GitHub.com 註冊一個免費帳號。
  2. 建立新 Repository（儲存庫）：點擊右上角「+」-> 「New repository」，命名為 daytrade-app，勾選「Public」。
  3. 上傳 index.html：將剛才下載嘅 index.html 檔案直接拖放上傳到 Repository 入面。
  4. 開啟 Pages 部署：
    • 點擊 Repository 頂部嘅 Settings 頁籤。
    • 左邊 Menu 揀 Pages。
    • 喺 Build and deployment 下面，將 Source 改為 Deploy from a branch，Branch 揀 main / root，按 Save。
  5. 搞掂！ 1-2 分鐘後，GitHub 會畀你一個正式嘅 https://... 網址！
最快方法

完全唔使寫 Command Line，直接將資料夾「拖放」落網頁度，10 秒內生成 HTTP 網站！

  1. 喺電腦建立一個名為 MyDayTradeApp 嘅資料夾，將 index.html 放入去。
  2. 前往 Netlify Drop (netlify.com/drop) 或者註冊 Vercel。
  3. 將成個 MyDayTradeApp 資料夾用滑鼠拖放（Drag & Drop）去頁面中央。
  4. 系統會自動建置，並即刻產生一個自訂嘅 https://xxxxx.netlify.app 網址畀你！
本機測試

如果你只係想喺你自己部電腦以 http://localhost:8080 形式執行：

方法 A: 用 VS Code Live Server 套件（最簡單）

喺 VS Code 安裝 Live Server Extension，開 index.html 按右鍵選 "Open with Live Server" 即可以 http://127.0.0.1:5500 執行。

方法 B: 用 Python（Terminal 指令）

喺 CMD / Terminal 進入放 index.html 嘅資料夾，輸入：

python -m http.server 8000

然後喺瀏覽器打開 http://localhost:8000

方法 C: 用 Node.js http-server

npx http-server .
